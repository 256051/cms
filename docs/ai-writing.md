# AI 写作助手

管理员在 **系统管理 → AI 写作设置** 填写 API 地址、API Key 和模型名称，勾选启用并保存。配置加密存入数据库，无需重启。模型由服务商提供，不预设模型、不安装额外 SDK。

保存后点击 **测试连接**：系统实际请求模型返回一小段文字，只有收到有效文字才显示通过。修改配置后需要先保存再测试。测试与生成都会使用服务商额度；配置完整不等于服务可用。

## 支持的接口

- 兼容 OpenAI **Chat Completions** 的非流式文本接口，使用 `Authorization: Bearer <API Key>`、`model` 和 `messages`。不支持仅提供 Responses、Anthropic Messages 或专有鉴权协议的地址。
- API 地址可以是 `https://api.example.com/v1`，也可以是完整的 `https://api.example.com/v1/chat/completions`。基础地址需要包含服务商要求的路径；程序只补 `/chat/completions`，不会猜测是否需要 `/v1`。
- 仅支持公网 HTTPS 地址；拒绝内网、本机和云元数据地址，连接时校验 DNS 解析结果并连接该地址，不跟随重定向、不使用系统代理。
- 单次请求最长 90 秒，响应最多 1 MiB、生成文字最多 100,000 字符。不自动重试，避免重复消耗额度；错误不会回显服务商原始响应或密钥。

协议参考：[官方 OpenAI Chat Completions 文档](https://developers.openai.com/api/reference/typescript/resources/chat/subresources/completions/methods/create)。

## 编辑器使用

管理员和编辑在文章或富文本页面编辑器点击 **AI 写作助手**，选择操作：

- 按主题写文章：填写主题和要求，生成 HTML 正文。新文章未填标题时，应用会取主题第一行作为标题，可继续编辑。
- 生成摘要：生成不超过 500 字符的摘要。
- 优化标题：生成一个不超过 200 字符的标题。
- 推荐标签：从已存在的标签中推荐最多 5 个，应用时保留原有标签，不自动创建标签。
- 翻译正文：填写目标语言，要求模型保留排版、链接、图片和代码。
- 润色正文：要求模型保留原意、事实和排版。

输入正文最多 100,000 字符、写作要求最多 4,000 字符；超限会提示缩短，不静默截断。只有点击生成时，当前标题、正文、要求以及标签推荐所需的可用标签会发送给所配置服务商。

生成结果先展示为预览。正文经过现有 HTML 清洗，预览使用禁用脚本和外部资源的独立框架；只展示文字排版，隐藏媒体。生成失败、关闭窗口或放弃结果均不会修改正文。生成过程不保存文章，也不发布或同步公众号。

点击 **应用** 才将结果写入相应字段，正文操作会替换当前正文。随后复用现有本机恢复、5 秒自动保存草稿、版本冲突保护和手动保存流程。已发布文章的公开版本不变，需要人工另行发布；原有定时发布计划仍按站点既有规则处理。模型输出的事实和排版需人工核对。

## 配置与权限

- 配置和连接测试只允许管理员操作；生成允许管理员和编辑使用，访客、咨询专员无权访问。
- API Key 不回显，留空保存时仅在 API 地址未变化的情况下保留旧密钥，更换地址需填写新密钥。关闭助手可保留配置。
- 配置写入沿用审计事务和乐观版本号；每个用户每分钟最多 10 次测试或生成请求，Cookie 写入接口仍校验 CSRF。
- 默认读取数据库。可通过现有 Consul / 环境变量 / 配置文件链覆盖 `AI:Enabled`、`AI:ApiUrl`、`AI:ApiKey`、`AI:Model`。任一字段显式覆盖时后台只读；更换地址的覆盖不会复用旧地址的数据库密钥。
- 环境变量分别为 `AI__Enabled`、`AI__ApiUrl`、`AI__ApiKey`、`AI__Model`；Consul 使用 `AI` 对象及相同字段名。希望后台管理时，不要配置这些覆盖项。

## 数据升级与验证

schema 19 → 20 只新增 `cms_ai_settings`，不改变现有业务表。启动时按现有迁移流程创建；逻辑备份包含配置，旧备份恢复时补空配置。恢复加密配置需要配套站点密钥目录。

可重复运行的检查：

```powershell
dotnet build --no-restore
dotnet run --project tests/Cms.Checks --no-build -- --ai-writing
python tests/ai_writing_acceptance.py
npm --prefix web run api:types
npm --prefix web run typecheck
python tests/ai_writing_browser.py
```

数据库、HTTP 和浏览器检查使用隔离 SQLite 站点。服务层使用模拟模型响应验证请求格式和失败处理；浏览器仅模拟模型生成/连接测试回复，配置和草稿保存访问真实本地 API。没有真实服务商密钥时，这些检查不代表外部模型已经联调通过。
