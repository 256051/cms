# 内容工作台视觉与交互

采用 ui-ux-pro-max 的通用可访问性指导及本次确认的产品方向。技能的两次设计系统检索偏展示页，未直接采纳其布局和配色。

- 简体中文，系统字体；浅灰工作区、白色面板、蓝色主操作。
- 后台侧边导航与独立滚动内容区；移动端导航抽屉可关闭，操作控件至少 44px。
- 文章编辑区为正文与发布设置两栏，小屏上下排列；保存、预览、发布含义明确。
- 前台以正文可读性为主，列表封面保留空间，正文限制行宽，图片自适应。
- 所有输入提供可见标签；错误使用 alert，成功/加载使用 status；保留键盘焦点与跳转链接。
- 尊重 reduced-motion；不加载远程字体、统计脚本或追踪器。
- 发布前检查 375、768、1024、1440 宽度，含空数据、错误、长标题和富文本表格。
