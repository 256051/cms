# 丰富内容编辑器

文章和独立页面共用同一个编辑器。基于现有 React/Tiptap 独立实现，参考 [Halo 编辑器接入说明](https://docs.halo.run/developer-guide/plugin/extension-points/ui/editor-create) 和截图中的操作方式；不加载 Halo 的 Vue 插件。

## 编辑与插入

- 选中文字后设置粗体、斜体、下划线、删除线、文字颜色、黄色高亮、上/下标、行内代码；支持系统/衬线/等宽字体、12–40 px 字号和 1.2–2.5 倍行距。
- 支持正文、二/三/四级标题、对齐、有序/无序列表、引用、分隔线、链接、撤销/重做和清除格式。链接对话框支持 HTTP(S)、站内路径、邮件和锚点；清空地址可移除链接。
- 点击“插入”，或在空段落输入 `/`，选择附件、图片、图片集、视频、音频、表格、网页嵌入、代码块或分栏。快捷菜单支持方向键、Enter、Escape；弹窗支持 Tab 和 Escape。
- 图片可从附件库选择，也可上传、直接粘贴截图或拖入图片文件。支持批量图片上传，每次最多 30 张。上传部分失败时保留已成功上传的图片并显示错误。
- 点击图片后打开“图片设置”，填写说明并设置 25/50/75/100% 宽度与左/中/右对齐。说明作为 `alt` 保存。
- 图片集按勾选顺序插入，可跨页选图、切换二/三列或解散为独立图片。附件窗口的搜索仅筛选当前页，翻页可查找其他附件。
- 选择表格单元格后可以增删行列、切换表头、删除表格；拖选多个单元格可合并，选中合并后的单元格可拆分。新建表格上限为 20 行、10 列。
- 代码块支持纯文本及 C#、JavaScript、TypeScript、JSON、HTML、CSS、Python、SQL、Bash 的语言标记；本次没有加入语法高亮引擎或代码执行功能。
- 分栏支持二/三栏，每栏独立编辑；手机前台自动排为单列。可以删除整个分栏，误删可立即撤销。
- 工具栏右侧按钮可收起/显示发布设置；桌面长文的工具区随滚动保持可用。Ctrl/⌘+S 保存草稿，不会自动发布。

## 文件和网页嵌入

附件支持 PNG、JPEG、GIF、WebP、PDF、MP4、WebM、MP3、WAV。后端检查文件扩展名、签名和媒体容器结构，并使用确定的 MIME 类型返回；不执行转码或病毒扫描。视频实际播放还取决于浏览器支持的编码，优先使用通用的 MP4/H.264 或 WebM。PDF 以下载附件返回。

图片、视频和音频必须先上传，正文使用附件库提供的 `/media/{id}` 地址；不能直接插入外部媒体 URL。未发布的附件只允许登录编辑人员读取，已发布文章引用的媒体才向访客开放，音视频支持分段请求。草稿或已发布版本引用的附件不能直接删除。

文件大小沿用 `Storage:MaxBytes`：默认 10 MiB，最多 50 MiB；继续支持本地配置、Consul 和环境变量 `Storage__MaxBytes`，无新增配置。视频较大时先压缩到部署限制内。

网页嵌入只接受公开域名的 HTTPS URL，拒绝 IP、本机/常见内网域名、非标准端口和含账号密码的地址。不接受自定义 HTML。后端不抓取该网页；浏览器通过 `sandbox="allow-scripts"`、`referrerpolicy="no-referrer"` 和延迟加载显示内容，不授予同源、表单、弹窗、下载、顶层导航或设备权限。受限框架可能无法运行需要这些能力的第三方组件；对方设置 X-Frame-Options/CSP 禁止嵌入时会显示失败，改用普通链接。

## 保存与显示

标题、摘要、分类标签、封面和发布流程沿用现有功能。草稿保存经过 .NET 允许列表净化，保存后的结果回填编辑器。脚本、事件、危险 CSS、自定义 class、任意布局参数及 iframe 额外权限会被删除或拒绝。Agent API 使用相同的净化及附件验证。

正常编辑已发布文章不会改变线上版本；只有“保存并发布”更新前台。版本冲突返回明确错误，保存失败保留当前输入。离开仍有修改的页面会触发现有未保存提示。

四套主题、独立页面和权限预览使用同一套正文 HTML 与样式。升级后历史内容无需迁移，无数据库结构变更；继续采用 schema 6。部署需一起更新 API 和 web，以免旧后端删除新增格式。更新前备份数据库、附件和密钥，流程见 [备份恢复](operations.md)。
