# 页面搭建与模板

首页和独立页面使用 GrapesJS 拖拽画布设计，支持可复用模板、常用模块、设备预览，以及模板的发布与历史恢复。页面沿用当前主题的配色，旧文章和富文本页面继续使用原有编辑方式。

后续新增的撤销／重做、模块富文本、手机独立样式、公共区块、产品／案例和 SEO 见 [页面搭建与业务工具](next-enhancements.md)。当前 schema 为 14；本文末尾保留初版 schema 10 的历史验收记录。

## 使用流程

1. 打开“独立页面”，新建或编辑页面，点击“使用页面搭建”。已有富文本转换时保留文字；已保存的原排版可从历史恢复。
2. 展开“模板、公共区块与页面设置”，选择企业首页、产品介绍、关于我们或联系我们起始模板，也可选择模板库中的已发布模板。
3. 从左侧将模块拖入中间画布，或点击添加。点击画布中的模块后在右侧编辑图片、链接等设置；双击标题和纯文本说明可直接输入。选中模块后使用画布移动手柄拖动排序，也可使用右侧上移／下移、复制、隐藏和删除按钮。“页面结构”提供可用键盘操作的模块选择入口，“外观与手机样式”收起非必要设置。可点击“展开设计器”扩大编辑空间。
4. 画布可切换电脑、平板和手机宽度。需要核对完整页面时展开“整页预览”，其中页头、页脚、菜单、主题和已发布动态内容均来自当前站点；预览禁用跳转和咨询提交。设计画布中的文章列表、同步公共区块使用提示占位，隐藏模块保持可选以便恢复。
5. 保存草稿或发布页面。自动保存、本机异常恢复、版本冲突保护继续有效，修改草稿不会改变公开页面。
6. 要设为首页，在“站点设置 → 文章显示 → 网站首页”选择已发布的独立页面并保存。取消选择恢复原博客首页；页面下架时自动回到博客首页，重新发布后继续显示所选页面。删除首页前需先更换首页设置。

## 模块和外观

- 首屏横幅：标题、说明、图片、按钮。
- 文字介绍：多段文字、富文本与按钮。
- 图片展示：附件库图片及图片说明，支持直接上传。
- 图文卡片：图片、标题、说明、链接，桌面 1–4 列。
- 内容列表：选择文章、产品或案例，可按分类筛选，按首次发布时间倒序动态展示 1–12 条已发布内容。
- 常见问题：可展开的问题与答案。
- 行动按钮：说明和跳转入口。
- 客户咨询：将现有咨询表单放入指定模块，提交继续进入咨询跟进；每页最多一个。

每页最多 40 个模块，卡片／问答每组最多 12 项。可以调整页面宽度、标题和页头页脚显示，设置模块背景风格、对齐和留白。卡片在平板最多两列、手机单列；使用主题已有的明暗配色。隐藏模块保留在草稿及历史中，发布快照不包含隐藏模块。

GrapesJS 0.23.6 随站点构建，进入设计器时按需加载，不依赖外部 CDN、账号或遥测服务。当前接入的是 CMS 现有模块，未开放任意 HTML/CSS、脚本导入及任意嵌套布局；布局继续存入原有 `LayoutJson`，服务端校验、图片引用保护和发布渲染保持一致，无数据库结构迁移。旧页面和模板可以直接继续编辑。

## 模板的复用和恢复

“页面模板”入口提供列表、新建、复制、发布、下架和回收站。也可在页面编辑时使用“另存为模板”，生成模板草稿。模板发布后才出现在页面搭建器的选择列表。

使用模板时复制布局到当前页面，随后独立编辑；更新、下架或删除模板不会修改已使用它的页面。模板本身的保存、定时发布、历史查看、恢复、回收站沿用内容机制。历史恢复只更新草稿，需重新发布才更新可选模板。

模板不会出现在公开内容接口、搜索、站点地图、评论或访问统计中。模板图片仅被模板引用时也不公开；实际页面发布并引用图片后，访客才可读取。草稿、隐藏模块、历史和回收站中的附件与分类引用仍受保护。

## 数据与部署

schema 9 → 10 增加 `cms_content.LayoutJson` 和 `cms_settings.HomePageId`，旧记录补空值。模板使用内容表中的 `template` 类型，沿用版本与发布快照；布局为受验证的数据，不能上传或执行模板代码、脚本及任意 CSS。FreeSql 编号迁移会在 API 容器启动时自动执行，完成前不提供服务；需更新 API 和 web 镜像。升级前保留数据库、附件、密钥与配置备份。

逻辑备份包含布局、模板、历史与首页选择。新备份为 schema 14，也可将 schema 9–13 备份恢复到全新环境并补齐新增字段。恢复继续拒绝非空数据库与目录。

当前沿用单站点、单 API 实例和 Admin／Editor 发布权限。同步公共区块、产品字段、页面级 SEO 和自定义表单字段已接入；不提供可执行的代码模板包。
