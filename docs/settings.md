# 站点设置

入口：后台 `/admin/settings`。只有管理员可读取管理配置并保存，所有设置一次保存并立即应用到四套主题。参考 [Halo 站点设置](https://docs.halo.run/guide/use/settings)，本次按确认的范围完善常用设置。

## 基本信息

- **站点名称**：最多 100 字，用于前台品牌名称和页面标题。
- **站点副标题**：最多 100 字，展示在网站顶部名称下方；留空隐藏。
- **站点介绍**：最多 500 字，供首页 SEO、没有摘要的页面、默认主题介绍及页脚使用。主题已填写自己的首页介绍时，仍以该主题配置为准。
- **Logo / 浏览器图标 Favicon**：从现有附件库选择图片。浏览器图标建议使用正方形 PNG；当前上传器支持 PNG、JPEG、GIF、WebP，不增加 ICO 或 SVG 上传。选中后访客可读取，被设置引用的图片不能删除；先清空或更换设置再删除。
- **内容语言**：简体中文、繁体中文或 English，设置网页 `lang`。这不会翻译正文、主题固定文案或后台；后台界面继续使用简体中文。

名称、介绍、副标题、关键词和页脚均为纯文本，不接受 HTML 或脚本。

## 文章显示

可分别设置首页、分类归档、标签归档和搜索结果的每页条数，范围 **1–50**，默认 **12**。保存后刷新前台即可看到新的条数和分页，不影响后台文章管理列表。

搜索页即使没有关键词，也使用搜索条数。主题预览复用同一列表规则，杂志主题仅首页第一页突出最新文章。已有公开 API 的显式 `pageSize` 参数继续保留（1–100 的既有限制）；正常前台使用站点设置。

## 搜索引擎

**屏蔽搜索引擎收录**开启后，网页输出 `noindex`，`robots.txt` 提示不抓取全站且不发布 sitemap 地址，`sitemap.xml` 返回空 URL 列表。关闭后恢复正常站点地图和抓取规则；后台、搜索和私密预览继续保留各自的禁止收录规则。

此开关不限制访客访问，也不能保证搜索引擎立即移除已经收录的页面。首页描述使用站点介绍，文章/页面优先使用自己的摘要；关键词使用英文逗号分隔，不保证搜索排名。

## 评论设置

- **启用评论**：影响文章和独立页面。关闭后隐藏评论区，公开评论列表为空，新提交返回 `403 / COMMENTS_DISABLED`。已有评论和审核状态保留在后台，重新启用后恢复。
- **新评论需要审核**：默认开启；新评论待审核。关闭后新评论立即公开，前台提示实际发布结果。已存在的待审核评论不会自动放行。
- **仅允许登录用户评论**：默认关闭。开启后要求现有的有效管理员或编辑账号，访客提交返回 `401 / COMMENT_LOGIN_REQUIRED`；前台提供新窗口登录入口，返回原窗口时重新读取会话。有效登录账号的评论使用账号姓名署名。

后台审核、删除、访客限流、纯文本展示及 CSRF 校验仍生效。主题预览始终禁止提交评论。没有开放访客注册或新增访客角色。

## 页脚与编辑保护

页脚文字最多 500 字，支持换行，在所有主题底部展示。留空或只填空白字符时显示默认“© 当前年份 IT猫 · itmao.club”，年份自动更新；填写后优先显示自定义文字。不提供 HTML 或脚本注入。

页面按五组排列，可使用分组链接快速定位；分组跳转不丢失编辑。底部保存栏显示未保存状态；失败和并发冲突保留表单，页面离开仍会提醒。每次成功保存更新版本号，可以继续编辑保存。遇到 `409 / VERSION_CONFLICT` 时，先保留自己需要的文字，再重新加载最新设置，避免覆盖其他管理员的改动。

## 接口、升级和边界

沿用 `GET/PUT /api/v1/admin/settings`、`GET /api/v1/public/settings`。保存必须携带读取时的 `version`，版本覆盖全部设置；保存、版本增加与 `settings.save` 日志处于同一事务。公开字段不包含数据库连接或任何通知密钥。

当前 schema **5** 在 `cms_settings` 添加上述常用字段和版本号，显式升级保留旧名称、介绍、Logo、关键词、主题和菜单。默认：中文、四类条数 12、允许搜索收录、启用评论、需要审核、允许访客评论，其他新增文字/图标为空。旧客户端只携带四个字段时最多按版本 0 保存一次，应按新 OpenAPI 契约读取并提交完整配置。

升级前停止服务并备份数据库、附件和认证密钥，按 [部署文档](deployment.md) 执行 `--migrate`；普通启动不自动修改结构。设置属于当前数据库中的业务数据，无新增 Consul 配置键。

按本次确认范围，未加入邮件/短信通知、访客注册、自定义网址规则、任意代码注入、文章别名策略、附件存储策略或后台品牌替换。当前固定网址保持有效。实际测试见 [验收记录](settings-verification.md)。
